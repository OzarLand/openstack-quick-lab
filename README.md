# openstack-quick-lab has moved

A complete, disposable OpenStack on cloud VMs in about an hour, exercises to break and repair it, and one command that deletes it all.

It is now **Quick lab**, the step *Discover* of **OzarLand Academy**, the learning path of
[OzarLand](https://github.com/OzarLand/ozarland):

- **Read it:** <https://academy.ozarland.com/lab/>
- **Sources, with their whole history:** [OzarLand/ozarland-academy](https://github.com/OzarLand/ozarland-academy),
  under [`docs/lab/`](https://github.com/OzarLand/ozarland-academy/tree/main/docs/lab)
- **Issues and contributions:** [OzarLand/ozarland-academy](https://github.com/OzarLand/ozarland-academy/issues)

The lab scripts are now under `docs/lab/variants/` of ozarland-academy:

```bash
git clone https://github.com/OzarLand/ozarland-academy.git
cd ozarland-academy/docs/lab/variants/openstack-cloud    # or openstack-cloud-multinode
```

This repository is archived: it keeps its history and its issues up to the move, read-only. Every page of it has
its copy, with the same history, in ozarland-academy, where the pages now link to each other across the modules of
the academy.
